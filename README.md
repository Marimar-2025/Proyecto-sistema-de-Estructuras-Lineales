# Proyecto-sistema-de-Estructuras-Lineales

Sistema de Gestion de Soporte Tecnico Empresarial para **SaludConecta IPS**, una IPS ficticia con areas de admisiones, consulta externa, seguimiento ambulatorio, auditoria medica, facturacion, laboratorio y farmacia.

Programa en Java por consola que usa:

- **Arreglos**: areas de la IPS, categorias de problemas, prioridades, tipos y estados de equipo.
- **ArrayList**: empleados y equipos registrados.
- **Cola (Queue)**: solicitudes pendientes en orden de llegada.
- **Pila (Stack)**: historial de solicitudes solucionadas.

## Como ejecutarlo

```
javac SoporteSaludConecta.java
java SoporteSaludConecta
```
